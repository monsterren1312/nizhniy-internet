
Автоматически публикует главные новости Германиина русском языке в
Telegram-канал "🇩🇪 Новости Германии" (@UsaNewsmedia). Источники — RSS-ленты
(NBC News, CBS News, ABC News, NPR). Перевод и переписывание текста —
через Anthropic API (Claude). Публикация — через Telegram Bot API.
Запускается по расписанию через GitHub Actions, без сервера.

Это общий хаб-канал сети — в отличие от нишевых каналов (например,
immigration-usa-bot), здесь **нет узкой фильтрации по теме**: цель —
широкий поток новостей для быстрого набора подписчиков, часть которых
дальше перетекает в тематические/локальные каналы сети.

## Что нужно сделать один раз перед запуском

### 1. Канал уже создан

Канал "🇩🇪 Новости Германии" (https://t.me/UsaNewsmedia) уже существует.
Убедись, что бот **@aipostbot** добавлен туда админом с правом публикации
сообщений (если ещё не добавлен — сделай это сейчас).

### 2. TELEGRAM_CHAT_ID

Можно использовать `@UsaNewsmedia` напрямую как chat_id, раз канал публичный.

### 3. TELEGRAM_BOT_TOKEN

Тот же токен, что и у @aipostbot в других каналах сети (Tampa News,
CryptoMedia, immigration-usa-bot) — узнать через @BotFather → `/mybots` →
@aipostbot → `API Token`.

### 4. ANTHROPIC_API_KEY

Тот же ключ, что и в других ботах сети — можно переиспользовать.

### 5. CHANNEL_URL

`https://t.me/UsaNewsmedia`

## Настройка репозитория на GitHub

1. Создай новый **приватный** репозиторий на github.com (отдельный от
   immigration-usa-bot — каждый канал сети живёт в своём репозитории).
2. Залей туда все файлы из этой папки (bot.py, requirements.txt,
   .github/workflows/main.yml, state/seen.json, README.md) — сохраняя
   структуру папок как есть.
3. Зайди в **Settings → Secrets and variables → Actions → New repository secret**
   и добавь четыре секрета:

   | Имя секрета          | Значение                          |
   | --------------------- | ---------------------------------- |
   | `TELEGRAM_BOT_TOKEN`  | токен от @BotFather                 |
   | `TELEGRAM_CHAT_ID`    | `@UsaNewsmedia`                     |
   | `ANTHROPIC_API_KEY`   | ключ с console.anthropic.com         |
   | `CHANNEL_URL`         | `https://t.me/UsaNewsmedia`          |

4. Перейди во вкладку **Actions** репозитория — подтверди включение
   workflows, если GitHub попросит.

## Как проверить, что всё работает

1. Во вкладке **Actions** найди workflow **"USA News Hub Autoposter"**.
2. Нажми **"Run workflow"** для ручного теста.
3. Посмотри логи — сколько новостей найдено и что опубликовано.
4. Проверь канал в Telegram — должны появиться новые посты.

После этого бот запускается сам каждые 30 минут, максимум 1 пост за запуск
(регулируется `MAX_POSTS_PER_RUN`).

## Как добавить/убрать источники новостей

Открой `bot.py`, найди список `RSS_SOURCES` — добавь или убери словарь с
`"name"` и `"url"`. Изменения подхватятся при следующем запуске.

## Защита от повторов

Бот хранит в `state/seen.json` ссылки на уже опубликованные новости и хэши
заголовка+описания. GitHub Actions сам коммитит обновлённый файл обратно
в репозиторий после каждого запуска.

## Если что-то не публикуется

Смотри логи в Actions — частые причины:

- Бот не добавлен админом в канал → ошибка от Telegram API.
- Неверный `TELEGRAM_CHAT_ID` → "chat not found".
- Закончился баланс на Anthropic API → пост пропускается, бот не падает.
